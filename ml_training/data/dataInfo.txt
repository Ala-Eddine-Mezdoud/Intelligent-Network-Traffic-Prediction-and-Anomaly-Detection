# CICIDS2017 — Intrusion Detection Evaluation Dataset
> **Source:** Canadian Institute for Cybersecurity (CIC), University of New Brunswick (UNB)  
> **Official Page:** [UNB CICIDS2017](https://www.unb.ca/cic/datasets/ids-2017.html)

---

## 1. Overview

The **CICIDS2017** dataset is a comprehensive, labeled network intrusion detection benchmark released by the Canadian Institute for Cybersecurity. It was designed to address the critical shortcomings of the eleven existing IDS datasets evaluated since 1998 — most of which were found to be outdated, unreliable, lacking in traffic diversity, or missing key metadata and feature sets.

The dataset contains **both benign traffic and the most up-to-date common attack types**, captured over 5 consecutive days (Monday July 3 – Friday July 7, 2017). It is structured to closely resemble real-world network behavior.

---

## 2. Key Design Criteria

The dataset was constructed to satisfy **11 criteria** identified in the authors' evaluation framework (Gharib et al., 2016). No previous IDS dataset had satisfied all 11 simultaneously.

| # | Criterion | Description |
|---|-----------|-------------|
| 1 | **Complete Network Configuration** | Full topology: Modem, Firewall, Switches, Routers, and multiple OSes (Windows, Ubuntu, Mac OS X) |
| 2 | **Complete Traffic** | 12 victim machines + user profiling agent + real attacks from a dedicated attack network |
| 3 | **Labelled Dataset** | All flows labeled with benign/attack class, with precise timestamps |
| 4 | **Complete Interaction** | Covers both intra-LAN (within network) and Internet communication |
| 5 | **Complete Capture** | Mirror port / tap used — all packets captured and stored on a storage server |
| 6 | **Available Protocols** | HTTP, HTTPS, FTP, SSH, and email protocols all present |
| 7 | **Attack Diversity** | 8 attack categories based on the 2016 McAfee threat report |
| 8 | **Heterogeneity** | Traffic from main switch + memory dumps + system calls from victim machines |
| 9 | **Feature Set** | 80+ network flow features extracted via **CICFlowMeter**, delivered as CSV |
| 10 | **Metadata** | Fully documented: timestamps, attack schedules, flow labels, and network topology |

---

## 3. Traffic Generation

Background traffic was generated using the **B-Profile system** (Sharafaldin et al., 2016), which profiles abstract human behavior and generates naturalistic benign traffic. The dataset simulates **25 users** interacting via:

- HTTP / HTTPS
- FTP
- SSH
- Email (SMTP/IMAP/POP3)
